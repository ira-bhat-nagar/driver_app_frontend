# GoRush Driver Partner Flutter App 🚖

The official GoRush Driver Partner mobile application built with Flutter, Riverpod, and Dio.

## Key Capabilities
- **Instant Online / Offline Control**: Real-time presence broadcasting to backend dispatch engine.
- **Intelligent Dispatch Offers**: 15-second radial countdown alerts with upfront fare transparency.
- **Auto-Rematch Integration**: Declining or timing out an offer triggers instant seamless rematching to the next candidate.
- **Turn-by-Turn Navigation**: Pickup navigation, geofence arrived indicator, and destination navigation.
- **OTP Verification**: Secure 4-digit start OTP prevents fraudulent trips.
- **Earnings & Ledger**: Real-time breakdown of daily gross, platform fee cuts, net driver earnings, and weekly payouts.

## Getting Started
```bash
cd driver_flutter/frontend
flutter pub get
flutter run
```
